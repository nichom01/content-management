## What is Neversoft?

Neversoft is a full-stack Supplier Management System designed for hire and sales companies to manage their inventory, products, orders, and supplier relationships.

### Key Features

- **Product Catalog Management** - Manage products with detailed specifications and images
- **Order Management** - Track orders and sales transactions
- **Supplier Relationships** - Maintain and manage supplier information
- **Responsive Interface** - Modern, user-friendly web application

## System Components

- **Frontend**: React + TypeScript (supplier-ui)
- **Backend**: FastAPI + Python (neversoft-api)
- **CMS**: Hugo Static Site Generator (this site)
